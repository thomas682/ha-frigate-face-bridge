          MQTT
          
      MQTT verbindet die Bridge mit Home Assistant. Discovery erzeugt automatisch HA-Sensoren. Das Passwort wird nie im Klartext angezeigt.
      
          
          
          
          
          
          
          
          
          
          
      
        
      
        
      
          Frigate und Face Import
          
      Frigate Import liest Frigate-MQTT-Events. Face Import liest Events einer externen Gesichtserkennung. Der Kamera-Filter muss zum Frigate-Kameranamen passen, sonst werden Events ignoriert.
